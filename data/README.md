# Kesh capability dataset

- `kesh-intents.jsonl` — training utterances. Generated by `scripts/generate_kesh_intents.py`.
- `evaluation.jsonl` — held-out examples. Never used for training.

Labels are human templates, not zero-shot model output.

The Spring Boot runtime trains OpenNLP from `src/main/resources/nlp/kesh-intents.jsonl`.
Optional SetFit training: `ml/classifier/train_setfit.py`.
